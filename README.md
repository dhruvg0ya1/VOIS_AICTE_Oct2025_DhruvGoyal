# VOIS AICTE - Python and Data Visualization

Coursework from the VOIS (Vodafone Intelligent Solutions) AICTE programme,
October 2025: Python fundamentals through to exploratory analysis and
visualisation.

[![Python](https://img.shields.io/badge/python-3.10%2B-blue?style=flat-square&logo=python&logoColor=white)](https://www.python.org/)
[![Jupyter](https://img.shields.io/badge/Jupyter-notebook-F37626?style=flat-square&logo=jupyter&logoColor=white)](https://jupyter.org/)

---

## Contents

| File | What it covers |
|---|---|
| `Source_Code.ipynb` | The working notebook: data loading, cleaning, exploratory analysis and plotting |
| `Getting started with Basics of Python.pdf` | Module notes on Python fundamentals |
| `Data Visualization.pdf` | Module notes on visualisation technique |

## Run it

```bash
git clone https://github.com/dhruvg0ya1/VOIS_AICTE_Oct2025_DhruvGoyal.git
cd VOIS_AICTE_Oct2025_DhruvGoyal
pip install pandas numpy matplotlib seaborn jupyter
jupyter notebook Source_Code.ipynb
```
